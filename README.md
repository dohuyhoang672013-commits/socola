# socola - ChocoRank 🍫🍬

ChocoRank là nền tảng thống kê, đánh giá và bảng xếp hạng các loại socola và kẹo ngon nhất, được yêu thích nhất.

## 🚀 Tính Năng Chính
- **Bảng Xếp Hạng**: Đánh giá chi tiết điểm hương vị, kết cấu, độ tan chảy, giá trị theo từng loại socola và kẹo.
- **Bộ Lọc Thông Minh**: Lọc theo nồng độ cacao, phân khúc giá, xuất xứ (Việt Nam, Bỉ, Thụy Sĩ, Nhật Bản,...).
- **So Sánh Sản Phẩm**: Công cụ đối chiếu trực quan tối đa 3 loại cùng lúc.
- **Trắc Nghiệm Gu Vị Giác (Taste Quiz)**: Gợi ý sản phẩm phù hợp theo sở thích cá nhân.
- **Đăng Nhập / Đăng Ký**: Hệ thống quản lý tài khoản và giỏ hàng trải nghiệm.
- **Trang Quản Trị (Admin)**: Quản lý danh sách sản phẩm và đơn hàng.

## 🛠️ Cài Đặt & Chạy Thử
Chạy máy chủ cục bộ bằng Node.js thuần (không cần cài thêm dependency):
```bash
npm start
# hoặc: node local-server.js
```
Truy cập trình duyệt tại: `http://localhost:3000/`
